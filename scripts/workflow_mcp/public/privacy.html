Resolvent · Autonomio

Privacy

Updated 27 October 2026.

This statement covers the Resolvent plugin and Autonomio's public Resolvent workflow service.

The workflow service

The service supplies public Resolvent workflow files and compares protocol version numbers. It accepts protocol versions and normal MCP connection metadata, such as client name, client version and request identifiers. Its tools have no fields for questions, chat transcripts, repository names, world-model records or credentials. Do not send these materials to the service.

Inputs are processed in memory for the request. The application has no database or persistent request storage. Application request logging, analytics and tracking cookies are disabled. It does not sell data, build profiles or use request content to train models.

Cloudflare hosts the service and processes normal HTTP and network information, including the request source IP address and headers, to deliver and protect it. Cloudflare's own operational and security processing and retention are described in its privacy policy. Disabling application logs does not disable Cloudflare's infrastructure processing.

The service retrieves public workflow files from Autonomio's GitHub repository. It forwards no MCP request body, client metadata, credentials or conversation content to GitHub.

Your chat and world model

Your chat host processes the conversation under its own policies. When you request model access, the plugin uses your authorized GitHub connection or local GitHub session. Selected material goes to the repository you authorize; it does not pass through the workflow service. The repository owner and GitHub control that material's access and retention. Public repositories and public pull requests are visible to others.

Invoking Resolvent alone does not authorize reading or writing a world model. You can keep research in the chat, request reads, or explicitly select material to add. Uninstalling or disconnecting the plugin stops future use; it does not delete existing repository history or host conversations. Manage those through the relevant host, GitHub and repository controls.

Support and contact

Support is available through GitHub issues. An issue's username and contents are public and remain in project history until removed through GitHub's controls. Do not include confidential information. For private privacy questions, use the Autonomio contact page. Autonomio uses the name, contact details and message you provide to respond to your request and retains private correspondence for one year. Use the same contact page to request access, correction or deletion of that correspondence.
