# Resolvent 1.0.0 verification

This generic Autonomio release derives from the supplied Resolvent 1.4.1 package.
It retains the research/capture, canonical admission, independent review, CI,
correction, continuation and authorized guarded merge workflow. Repository
selection is supplied by the user in the invoking chat. No standing owner merge
delegation, organization-specific default or Portal capture dependency is shipped.

The bounded worker prompt, schema evaluator, installer, action pins, admission
reference, GitHub access reference, protocol schema, conversation example and
original SVG remain unchanged. All original integration test cases remain, with
one new regression for unconfigured disabled policy. The controller accepts an
empty repository only while disabled; enabled integration still requires an
explicit valid repository and every original authorization gate.
The disabled optional repository observer still requires its own repository-side
configuration; it is not required to invoke the chat plugin.

The root repository tests exercise distribution integrity and schema/version
consistency. The retained integration suite exercises the supplied observer and
installer. The source repository's `verification/source-preservation.json` records
unchanged, changed and removed files relative to the original ZIP; it is not bundled
as runtime configuration. Local checks are not hosted installation,
live admission, independent review, CI on a real contribution or merge evidence.

Both host distributions are built from one source and contain identical bytes.
No remote action is performed by either packaging script.
